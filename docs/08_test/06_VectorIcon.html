ベクターアイコン

ウェブコンテンツのアクセントになるアイコンは、Web フォントで提供し、動的 SVG でフォールバックする。これ以前は、Pure CSS Icon で提供されていました。しかし、もっさり感が耐えられなくなり、標準的な手段を採用しました。

一方で、現在はインライン SVG による実装が主流のようです。この手法は、SVG に非対応な非力なブラウザに、大量のマークアップをダウンロードさせてしまうことになるため、私はウェブ文書向けのプロジェクトでは採用しません。
